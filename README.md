## 📖 概要

参加者リストから複数人を一度に選べる、当選者抽選向けの静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

## ✨ 機能

- 参加者リストを1行1人で入力するテキストエリア（貼り付け対応）
  - 空行は無視されます
  - 同名でも別々の人として扱います（名簿の同姓同名対応。以前は同名の重複行を1人に統合していましたが、学校のクラス名簿などでの実用を優先して 2026-11-20 に仕様変更しました）
  - 参加者数をリアルタイム表示します
- 当選人数を指定して抽選（当選者の重複なし＝非復元抽出）
- 抽選アニメーション：名前が高速で切り替わるシャッフル演出のあと、当選者を結果表示
- 抽選履歴（時刻と当選者一覧、最新50件。履歴はメモリ内のみで、保存はしません）
- 「当選者を除いて再抽選」ボタン：過去の当選者を候補から外して再抽選できます。同名の別人は外れません（識別方法は [DESIGN.md](DESIGN.md) の判断記録を参照）
- 結果のコピーボタン（当選者一覧をクリップボードへ）
- 結果の印刷ボタン：印刷時は入力UI・履歴・説明などを隠し、当選者一覧だけが紙面に出ます（`@media print`）
- 参加者リストと当選人数の自動保存：入力・設定変更のたびに localStorage（キー `kujiya-data`、テーマ用 `kujiya-theme` とは別キー）へ保存し、次回開いたときに復元します。「リストをクリア」を押すと保存も消えます
- テーマ切り替え（ダーク／ライト。選択は localStorage に保存され、次回も維持されます）
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）

## 📝 使い方

1. 参加者を1行に1人ずつ入力します（名簿などをそのまま貼り付けてもOKです）。
2. 当選人数を指定して「抽選する」を押します。シャッフル演出のあと、当選者が表示され、履歴に残ります。
3. 続けて別の当選者を選びたいときは「当選者を除いて再抽選」を押すと、これまでの当選者を除いた候補から抽選します。
4. 「結果をコピー」で当選者一覧をテキストとして共有でき、「結果を印刷」で当選者一覧だけを印刷できます。
5. 参加者リストと当選人数は自動保存されるため、ページを閉じても次回そのまま続きから使えます。消したいときは「リストをクリア」を押してください。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。参加者リスト・当選人数・非復元抽選・シャッフル演出・過去の当選者を除く再抽選・履歴（最大50件、メモリ内のみ）・リストと当選人数の自動保存（ローカルファイル）まで Web 版と同じです。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Kujiya.exe` を生成します（GitHub Release にはバイナリを添付しない方針のため、配布物は各自ビルドしてください）
- Web 版の結果の印刷ボタンは Windows 版にはありません

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 抽選は Fisher-Yates シャッフル後に先頭から当選人数分を取る方式で、当選者の重複はありません。
- シャッフル演出は約1.8秒間、50ミリ秒間隔で候補の名前をランダムに切り替えて表示します。
- 入力内容はブラウザ内でのみ処理され、サーバーには何も送信されません（自動保存も localStorage のみ）。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: kujiya-v1）。
- 抽選の純粋ロジックは `js/draw-core.js` に分離してあり、`npm test` で単体テストできます。

## 🔗 関連

### ルーレット（ルレット）との違い

- **くじや**は、参加者リストから**複数人を一度に選ぶ「当選者抽選」**向けです。プレゼント企画の当選者決めなど、当選人数を指定して重複なく選びたいときに使います。
- **ルーレット**は、候補の中から**1つの項目を楽しく選ぶ**ためのものです。ホイールを回す演出で1つを決めたいときに使います。
